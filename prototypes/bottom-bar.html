When the gradient loses the color
Drag the card left to see the stops, right to go back. + adds a color between two existing ones, Figma-style: halfway, in the color the gradient already has there — so the sky doesn't change, a new handle appears. Pull a tag to the right, away from the card. It resists like a magnet, its color melting out of the sky as you go; at the let-go point it pops free, and releasing it there sends it off the edge. Let go early and it snaps back, color and all. Tap a tag to select it. The last color can't be removed.
